Vim 入门教程：从第一次打开到高效编辑代码

Vim 是 Linux、服务器、Git、Docker 等开发环境中常见的文本编辑器。

很多人第一次打开 Vim 时都会遇到同一个问题：

为什么我不能直接输入？又该怎么退出？

原因在于 Vim 和普通编辑器的设计思路不一样。

普通编辑器默认是“输入文字”，而 Vim 默认是“执行编辑命令”。
所以学习 Vim 的第一步是理解它的模式，背快捷键可以放在后面。

如果只是想先把 Vim 用起来，可以先记住下面四个操作：

命令 作用
i 进入 Insert Mode

Esc 返回 Normal Mode

N 上一个结果
v 字符选择
