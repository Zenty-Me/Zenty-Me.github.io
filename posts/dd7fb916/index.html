总结

总的来说，uv 提供了一套简洁高效的工作流。对于大多数项目，你只需要记住几个核心命令即可：

  1. uv init：初始化项目。
  2. uv add：添加依赖。
  3. uv run：在项目环境中运行代码。
  4. uv sync：同步项目环境。

路径操作

方法装饰器

FastAPI为标准的HTTP方法提供了对应的装饰器：

  • @app.get()：用于获取数据，不改变服务器状态。
  • @app.post()：用于创建新数据。
  • @app.put()：用于完整更新已有资源。
  • @app.patch()：用于部分更新已有资源。
  • @app.delete()：用于删除资源。

此外，也支持 @app.options() 和 @app.head() 等方法。
