常用命令速查

命令 作用
openspec init 初始化 OpenSpec
openspec update 更新 Agent Workflow
openspec list 查看当前 Changes
openspec list --specs 查看现有 Specs
openspec view 查看 OpenSpec 状态
openspec show <name> 查看某个 Change 或 Spec
openspec validate <name> 验证指定 Change
openspec validate --all 验证全部 OpenSpec 内容
openspec validate --all --strict 严格验证
openspec archive <change> 归档 Change
openspec status 查看状态
openspec schemas 查看 Schema
openspec config 管理配置
