Docker 是现在后端开发、微服务、DevOps、云原生开发中非常常见的一项技术。

很多人在第一次接触 Docker 时，会觉得它就是“启动容器的工具”，然后开始背各种 docker run、docker ps、docker exec 命令。

但如果只是记命令，其实很难真正掌握 Docker。

Docker 真正解决的问题，是：

如何把应用程序和它所依赖的运行环境统一打包，让程序在不同机器上都能够以相同的方式运行。

比如一个 Python 项目在本地运行正常，但是部署到服务器以后可能出现：

最终就会出现经典问题：

Docker 的作用，就是尽可能减少这种环境差异。

这篇文章会从 Docker 的核心概念开始，一直讲到镜像、容器、数据卷、网络、Dockerfile、Docker Compose，以及真实项目中的 Docker 使用方式。
