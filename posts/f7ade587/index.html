图床搭建

发表于2026-08-07|更新于2026-08-08|博客搭建
|浏览量:

1. 准备

  • github账号
  • PicList软件：https://github.com/Kuingsmile/PicList

2. 配置

2.1 github新建仓库+token获取

  1. 新建一个公开的仓库，eg：images-test

  1. 在设置页面申请token

2.2 PicList配置

  1. 打开下载好的PicList，对图床进行配置

CDN加速服务：PicList 支持给 GitHub 图床套一层 CDN 加速，常用的是 jsDelivr（https://cdn.jsdelivr.net/gh/用户名/仓库@分支/路径）。套上后图片走 CDN 节点，加载更快。

⚠️ 注意：jsDelivr 在国内不时会抽风（图片加载失败或很慢）。如果遇到加载不出来的情况，可以临时关掉 CDN 直接走 GitHub 原链，或换其他图床方案。
