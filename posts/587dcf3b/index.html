三、虚拟环境与依赖管理

uv 支持两种使用模式：

  1. 项目工作流：使用 pyproject.toml 与 uv.lock 统一管理依赖与环境，免去手动激活虚拟环境的步骤。
  2. 独立虚拟环境：沿用传统的 venv 与 pip 模式，适合轻量脚本或存量项目的平滑过渡。

六、常用命令速查

类别 命令 说明
Python 版本 uv python install <version> 下载并安装指定 Python 版本
uv python list 查看本地及远程可用 Python 版本
uv python pin <version> 将当前项目绑定至指定版本
项目依赖 uv init <name> 初始化 Python 项目
uv add <package> 添加依赖并写入 lock 文件
uv add --dev <package> 添加开发依赖
uv remove <package> 移除依赖项
uv sync 按照 uv.lock 同步当前环境
uv run <command> 在项目环境中执行脚本或命令
基础虚拟环境 uv venv 创建轻量虚拟环境
uv pip install <package> 安装指定 Python 包
独立工具 uvx <tool> [args] 在临时环境中执行 CLI 工具
