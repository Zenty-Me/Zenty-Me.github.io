1. 介绍

由于浏览器环境与node环境的差别，会导致浏览器的JavaScript代码没办法在node环境中正常执行，js代码会根据浏览器所提供的属性来判断你执行的环境是不是通过浏览器来执行的。如果不是则不会返回正确的响应信息

2. 浏览器中常见对象

1. window：窗口对象

window在浏览器中属于顶级变量，任何在全局作用域中声明的变量或函数都会成为window对象的属性。例如：如果你声明一个全局变量var name = 'admin';，你可以通过window.name获取。window仅在浏览器环境中存在，在node或者其他环境中，顶级对象为global。

2. document：文档对象

3. navigator：导航对象

4. location：地址栏对象

5. screen：屏幕对象

6. history：历史对象

7. locationStorage和sessionStorage：本地存储对象

8. element：标签对象

5. 原型和原型链

1. 基础

JavaScript 中，对象需要一个机制来共享属性和方法。如果每个对象都存储自己的方法副本，内存会严重浪费。原型系统正是为了解决这个问题而设计的。

2. 属性

prototype属性(函数独有)

每一个函数都有一个prototype属性，指向通过new创建的实例的原型

__proto__属性(对象独有)

每一个对象(除了null)都有一个__proto__属性，指向它的原型对象

constructor属性

原型对象上有一个constructor属性，指回构造函数本身

3. 使用

传统方法创建类，并将方法存储到公共空间

使用class关键字创建类并实例化对象(会将类中的方法放入公共空间)

4. 原型链

在继承多个类的时候，他的原型层数会比较多，会形成一个原型网络。那我们通过这个原型网上找的这个链路就称为原型链。

5. 原型链检测

Object.getOwnPropertyDescriptor() 静态方法返回一个对象，该对象描述给定对象上特定属性（即直接存在于对象上而不在对象的原型链中的属性）的配置。返回的对象是可变的，但对其进行更改不会影响原始属性的配置。
