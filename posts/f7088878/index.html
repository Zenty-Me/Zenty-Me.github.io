Alembic 使用教程

在 Python 后端开发中，只要项目使用了 SQLAlchemy，基本都会遇到一个问题：

数据库表结构发生变化之后，应该怎么安全地同步到数据库？

比如一开始我们有一个 users 表：

后来业务发生变化，需要增加：

如果项目还处于刚开始开发的阶段，我们当然可以直接删掉数据库重新创建。

但如果数据库中已经存在大量用户数据，这种方式显然不可行。

这时候就需要使用 Alembic。

Alembic 是 SQLAlchemy 官方推荐的数据库迁移工具，可以帮助我们管理数据库结构的变化，例如：

  • 创建、删除数据库表
  • 新增、删除字段
  • 修改字段类型
  • 创建索引和外键
  • 升级数据库版本
  • 回滚数据库版本
  • 记录数据库结构的历史变化

你可以简单地把 Alembic 理解为：

数据库结构的 Git。

Git 管理代码版本，而 Alembic 管理数据库结构版本。
