从零开始搭建 Hexo + Butterfly 博客（零基础教程）

发表于2026-08-06|更新于2026-08-08|博客搭建
|浏览量:

本篇面向完全没接触过代码的同学。跟着做完，你会得到一个有独立网址（你的名字.github.io）、能写文章、手机电脑都能看的个人博客。

一、先认识几个概念

别急着动手，花两分钟搞清楚我们在做什么。

名词 是什么 在本教程里干嘛
Hexo 一个博客生成工具 把你写的 Markdown 文章变成网页
Butterfly 一个博客主题（皮肤） 让博客好看
Node.js 运行环境 Hexo 依赖它才能运行
Git 版本控制工具 把博客推送到网上
GitHub 代码托管平台 免费存放你的博客
GitHub Pages GitHub 的建站服务 让别人能通过网址访问你的博客

一句话流程：用 Hexo 在本地写文章 → 用 Git 推到 GitHub → GitHub Pages 自动发布 → 全网可访问。

十、部署到 GitHub Pages

最后一步，把博客发布到网上。

1. 新建仓库

在 GitHub 点 New repository，名字必须是 用户名.github.io（用户名换成你的）。选 Public，其他不勾，创建。

2. 配置 SSH（让电脑有权推送到 GitHub）

一路回车。然后打开生成的公钥文件（Windows 路径 C:\Users\你的用户名\.ssh\id_ed25519.pub），用记事本打开，复制全部内容。

到 GitHub → 右上角头像 → Settings → SSH and GPG keys → New SSH key，Title 随便填，Key 粘贴刚才复制的内容，保存。

十三、常见问题

Q：hexo server 打不开 localhost:4000？
看命令行有没有报错。端口可能被占用，换一个：hexo server -p 5000。

Q：部署报错 Permission denied (publickey)？
SSH 没配好。重新按第十步生成 key 并添加到 GitHub，确认 ssh -T git@github.com 能通过。

Q：部署成功了但访问 404？
按顺序检查：仓库名是不是严格的 用户名.github.io；仓库是不是 Public；去仓库 Settings → Pages 看是否已开启。

Q：部署后看到的还是旧内容？
GitHub Pages 有缓存，等 1-2 分钟或 Ctrl+F5 强刷。也可去仓库 Actions 页面看部署状态。

Q：中文文章网址又长又丑？
默认网址带中文和日期。装 hexo-abbrlink 插件可生成 8 位固定短链，详见《文章分类、置顶与短链配置》。

Q：图片显示不出来？
在 _config.yml 设置 post_asset_folder: true，图片放文章同名文件夹，用裸文件名引用 ![](图片.png)。详见《Hexo 博客发布笔记完整教程》。

小结

步骤 命令 / 操作
装环境 Node.js + Git
装 Hexo npm install -g hexo-cli
建博客 hexo init
装主题 npm install hexo-theme-butterfly --save + 改 theme: butterfly
改配置 _config.yml + _config.butterfly.yml
写文章 hexo new "标题"
发布 hexo clean && hexo g && hexo d

搭一次，以后写文章只需要后两行。祝写作愉快。
