注意 name 前面是 4 个空格，link/avatar/descr 前面是 6 个空格，和同分类下其他书签对齐。

四、新建分类

在文件末尾追加一整组，class_name 顶格写，和文件里已有的分类对齐：

新分类前面留一个空行和上个分类隔开。

五、缩进规则（重要）

YAML 对缩进敏感，必须用空格，不能用 Tab：

层级 内容 缩进
1 class_name 0 空格（顶格）
2 class_desc / link_list 2 空格
3 name 4 空格
4 link / avatar / descr 6 空格

六、图标自动获取

avatar 字段填网站自己的 favicon，格式固定：

例如：

  • GitHub → https://github.com/favicon.ico
  • 掘金 → https://juejin.cn/favicon.ico

不用手动下载图标，浏览器会自动加载网站图标。

七、删除书签

找到对应书签的 4 行（name/link/avatar/descr），整段删除即可。注意不要破坏周围书签的缩进。
